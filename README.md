# LH Event Research Lab

한국 지방 준공후 미분양의 LH 매입 정책을 첫 전략으로 삼는 **정책 이벤트 기반 스페셜시츄에이션 리서치 + 가상매매 시스템**.

현재 단계는 `V0.1 Truth DB`다. 목표는 먼저 다음 연결을 틀리지 않게 저장하고 검증하는 것이다.

`아파트 사업장 -> 시행사/SPC -> 시공사/상장사 -> PF/미수금/대여금/재고 -> LH 매입 가능성 -> 상장사 경제적 효과 -> 주가 반응 -> 가상 진입/청산`

## 핵심 원칙

- LLM은 문서 해석, 검색어 생성, 가설 생성, 여러 데이터 층의 관계 해석에 사용한다.
- 미분양 세대수, PF 금액, 시가총액, 가격, 수익률, HH/HL/LH/LL 같은 사실은 원본 데이터와 코드가 결정한다.
- 모든 핵심 사실에는 출처를 붙인다.
- `시공사 = 미분양 소유자`라고 자동 가정하지 않는다.
- LH 매입가격 자체를 상장사 수혜액으로 바로 계산하지 않는다. PF 상환, 공사미수금 회수, 대여금 회수, 직접 재고, 보증위험 감소의 연결을 따로 본다.
- LLM이 제안한 가상 주문은 Risk Engine 검사를 통과해야 체결된다.

## V0.1 포함 기능

- SQLite Truth DB
- 회사/사업장/출처 등록
- 사업장-상장사 경제적 노출 연결
- LH 매입 가능성 시나리오 저장
- 지역 펀더멘털 점수 저장
- 회사별 예상 수혜액/시총 대비 효과 요약
- 시장구조 스냅샷 저장
- LLM 투자판단 레코드 저장 구조
- 가상매매 레코드 기반
